Have an AI agent template worth sharing?

Feel free to open a pull request and add it to the collection.

Please make sure the project is open source, actively maintained, and provides a useful starting point for building AI agents.

## About Vectoree

[Vectoree](https://vectoree.ai/) provides infrastructure for building and running AI agents, including model access, authentication, database, storage, and other backend capabilities.
